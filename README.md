# AI Order Automation System

## Project Overview
This project automates order processing using n8n and AI. It receives order information through a webhook, extracts customer details and order amounts using Google Gemini, detects duplicate orders, and classifies orders by priority.

## Tools & Technologies
- n8n — Workflow automation
- Google Gemini — AI-powered data extraction
- Telegram Bot — Order notifications
- Google Sheets — Order data storage
- Webhooks — Receiving order requests

## Key Features
- Extracts customer names and order amounts from messages
- Detects duplicate orders
- Classifies orders based on order amount
- Sends Telegram notifications for priority orders and orders requiring review
- Saves order details in Google Sheets

## What I Learned
- Building multi-step automation workflows
- Integrating AI models with external services
- Working with webhooks and JSON data
- Implementing conditional logic and duplicate detection
- Connecting APIs and handling workflow errors
